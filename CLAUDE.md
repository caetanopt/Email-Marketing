# Instruções para Claude Code

## Regra obrigatória

**Após qualquer alteração ao projeto, commit e push sempre para o branch `claude/continue-session-bXdP8`.**

O ficheiro principal do mockup é `app-preview.html`. Sempre que for modificado — ou sempre que qualquer outro ficheiro for alterado — é obrigatório:

1. `git add app-preview.html` (ou os ficheiros alterados)
2. `git commit -m "mensagem descritiva"`
3. `git push -u origin claude/continue-session-bXdP8`

Nunca terminar uma tarefa sem fazer commit e push.
